# M2.1 Implementation Report — Initial A1–A3 and B4 Product-Stage Carbon Consequences

## Checkpoint objective

M2.1 introduces the first executable carbon consequence calculation while preserving all previously verified economic and lifecycle outputs. The checkpoint is intentionally limited to:

- initial product-stage `GWP_TOTAL` reported as A1–A3 for components that are `NEW_AT_T0`; and
- product-stage `GWP_TOTAL` associated with canonical `B4_REPLACEMENT` lifecycle events, reported to B4.

It does **not** calculate A4, A5, B1–B3, B5–B8, C1–C4, D1–D2, operational carbon, residual value, marginal abatement cost, stakeholder carbon allocation, an A–C total, or Whole-Life Carbon.

## Architecture implemented

A new module, `carbon_consequences.py`, consumes three previously frozen layers:

1. canonical physical lifecycle events from `lifecycle_event_ledger.csv`;
2. explicit one-to-many BoQ mappings from M1.7; and
3. explicit environmental-factor assignments and unit-compatibility gates from M1.8.

The carbon engine never samples component service life. Every B4 carbon consequence is traceable to one canonical lifecycle `event_id`. Event time, future, scenario, component identity and generation are reconciled against the canonical event before impact calculation.

### Initial product-stage rule

`NEW_AT_T0` components receive initial product-stage consequences at `t = 0`.

`RETAINED_EXISTING` components receive **no historical A1–A3**. Their first post-t=0 product consequence occurs only if/when a modeled replacement event occurs and is then reported in B4.

### Replacement product-stage rule

For each canonical `B4_REPLACEMENT` event, the engine uses the same mapped BoQ line and the same passing environmental factor set. Product manufacturing factors whose source scope is `A1-A3` or complete non-overlapping `A1`, `A2`, `A3` are mapped to the B4 replacement consequence. They are not re-added to initial A1–A3.

### Factor and uncertainty rule

Only `GWP_TOTAL` is executable in M2.1. It is never reconstructed from `GWP_FOSSIL`, `GWP_BIOGENIC`, or `GWP_LULUC`.

Environmental-factor uncertainty metadata are retained, but factor uncertainty is not sampled yet. M2.1 applies the source dataset's central factor value and records:

`factor_temporal_basis = STATIC_REFERENCE_FACTOR`

for both initial and future replacement consequences. Therefore future manufacturing decarbonisation is **not** inferred or modeled in this checkpoint.

Carbon is not financially discounted.

## New outputs

- `carbon_consequence_ledger.csv` — row-level traceable product carbon consequences;
- `assessed_product_carbon_by_module.csv` — per-future/per-scenario assessed A1–A3 or B4 product-stage totals;
- `product_carbon_coverage.csv` — BoQ-line execution/blocked status;
- `carbon_engine_status.json` — machine-readable scope and claim guard.

The consequence ledger carries lifecycle identity, BoQ identity, factor set/record identity, dataset and product identity, declared unit, source factor module scope, reported module, resolved activity quantity, factor value, calculated kgCO2e, mapping basis, unit conversion method, source citation, verification/data-quality/licensing metadata, uncertainty metadata and temporal-basis provenance.

## Research-integrity guards

- Missing BoQ/factor/assignment data never become zero.
- BoQ factors are never inferred from names, cost, or similarity.
- Unit conversion reuses the frozen M1.8 compatibility gate.
- Historical A1–A3 is excluded for retained components.
- B4 timing is inherited from canonical lifecycle events, with no carbon-side resampling.
- Reference and intervention component sets are isolated; a BoQ line belonging to another component set cannot leak into initial A1–A3 calculation.
- Future product factors remain explicitly static until a later time-dependent embodied-factor method is introduced.
- No Whole-Life Carbon label is emitted.

## Deterministic verification fixtures

A closed-form synthetic fixture uses 10 m2 of product and a factor of 2.5 kgCO2e/m2:

- initial A1–A3 = 25 kgCO2e;
- one B4 replacement = 25 kgCO2e.

Additional tests verify retained-component exclusion, one initial consequence per future, B4 event/consequence identity, disaggregated A1/A2/A3 summation without overlap, kg↔tonne conversion, missing-GWP blocking, duplicate assignment blocking, 30/50/60 horizon nesting, and intervention/reference scope isolation.
