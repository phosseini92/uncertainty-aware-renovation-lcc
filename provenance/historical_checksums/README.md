# Historical milestone checksum manifests

These manifests belong to earlier frozen milestone snapshots (M1.x, M2.x and M3.1). They are preserved for provenance only and are **not expected to validate the current M3.1.1 working tree**, because later milestones add or update source/documentation/output files.

Use the root-level `SHA256SUMS.txt` and `M3.1.1_SHA256SUMS.txt` for current-release integrity.
